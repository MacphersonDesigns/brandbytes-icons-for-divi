# Essentials icon library

The Essentials library contains 16 original geometric interface icons created
for this project. They are not copied from Divi, Font Awesome, or another icon
pack.

- Copyright: 2026 Code & Canvas contributors
- License: GPL-2.0-or-later
- Manifest schema: version 1
- Artwork format: standalone sanitized SVG

The manifest UUIDs are persistent content identifiers. Never regenerate or
reassign an existing UUID after release: saved Divi modules refer to those
values directly.

New artwork must include a manifest entry with a unique UUID, human-readable
name, category, keywords, and relative file path. Contributors must confirm
that they created the artwork or have explicit GPL-compatible redistribution
rights.
